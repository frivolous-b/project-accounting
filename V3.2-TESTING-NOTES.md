## 3. Edit mode (`?edit=1`)

### 3a. Първи login

1. Отвори `index.html?edit=1`
2. Получавай password prompt → въведи `qwe@123`
3. **Очаквай:** forced password change screen
4. Тест invalid пароли:
   - [ ] < 8 знака → „Минимум 8 знака."
   - [ ] Несъвпадащи → „Паролите не съвпадат."
   - [ ] Същата `qwe@123` → „Тази парола е резервирана."
5. Валидна нова парола (≥ 8 знака, различна от резервирани) → edit mode active
6. Toast: „Паролата е зададена. Пази се само в този браузър."

### 3b. Повторен login

- [ ] Затвори и отвори браузъра отново с `?edit=1`
- [ ] Въведи вашата парола → влиза директно (без forced change)
- [ ] DevTools → Application → Local Storage → има `expert_pwd_hash` (SHA-256 hex)

### 3c. Rate limiting

1. Опит 1 (грешна) → „Грешна парола. Остават 2 опита."
2. Опит 2 (грешна) → „Грешна парола. Остават 1 опита."
3. Опит 3 (грешна) → блокиращ overlay „Опитайте отново след 5 мин"
4. „Затвори" → редирект без `?edit=1`
5. Опит преди 5 мин да минат → пак блокиращ overlay
6. След 5 мин → нормален login отново

### 3d. Master recovery

- Master парола: **известна само на разработчика**
- [ ] Винаги работи, дори при rate limit
- [ ] Audit log записва `login_success: master_recovery`

### 3e. Време на достъп (Europe/Sofia)

- [ ] Извън пон-пет 08:00-22:00 → overlay „Извън работно време"
- [ ] Бързотест: console → временно подмени `getSofiaHour = () => 23;` → блокира

### 3f. Idle timer (30 мин auto-logout)

- [ ] Login → activate edit mode
- [ ] Не пипай 30 мин → toast „Автоматично излизане" → редирект
- [ ] Бързотест: смени `IDLE_LIMIT_MS = 10 * 1000` за 10 сек, тествай, върни на 30 мин

## 6. Download function

1. Login → направи 2-3 промени (текст / цвят / снимка) → „💾 Изтегли сайта"
2. Получаваш нов `index.html` в Downloads
3. Отвори новия файл — провери:
   - [ ] Промените запазени в HTML-а
   - [ ] Цветовете запазени в `:root` блока на `<style>`
   - [ ] Edit mode UI **не** е в downloaded HTML (no `.edit-bar`, `.color-panel`, `.toast`)
   - [ ] В `<head>` има инжектиран коментар за `localStorage` password behavior
4. Отвори новия файл в **друг** браузър с `?edit=1` → иска първоначална парола (защото localStorage е празен в новия браузър)
